# Exploring Reality (Android app)

This repository holds only the released Android app for the personal build of **Exploring Reality**, a teaching game grounded in Dzogchen and Tibetan Buddhism. No source code lives here.

- Download the newest `ExploringReality.apk` from **Releases**.
- Install it over an older build; saves are kept.
- When the app is opened online, it checks here and shows an "Update now" banner when a newer build exists.
